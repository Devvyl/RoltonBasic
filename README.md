## English

*RoltonDevvyl* - functionaly-based programming language on C++.

It supporting:
- 2 types
- 4 command
- translating on 1 language

Example of code:

```RoltonDevvyl
VARINT a 5
VARSTR b "Nagaev"
PRINT "My num is "
PRINT a
PRINT "\nMy colleague is "
PRINT b
TYPE a
TYPE b
```

## Русский

*RoltonDevvyl* - функционально-ориентированный язык программирования на C++.
Является форком проекта RoltonBasic, этот форк нацелен на совместимость с оригиналом, но с более менее адекватными реализациями.

Он поддерживает:
- 2 типа
- 4 команды
- трансляцию на 1 язык

Пример кода:

```RoltonDevvyl
VARINT a 5
VARSTR b "Nagaev"
PRINT "My num is "
PRINT a
PRINT "\nMy colleague is "
PRINT b
TYPE a
TYPE b
```
